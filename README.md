# 2024 LG Aimers 5기 - 제품 불량 여부 예측 모델링

본 저장소는 2024년 7월부터 8월까지 진행된 LG Aimers 5기 프로그램에서, 제품 생산 공장 데이터를 기반으로 제품 불량 여부를 예측하는 이진 분류(Binary Classification) 머신러닝 파이프라인을 구축한 과정을 기록한 아카이브입니다.

## 프로젝트 개요
- **목적**: 대규모 제조 센서 및 공정 데이터를 분석하여, 최종 제품의 정상/불량 상태를 예측하는 AI 모델 개발.
- **핵심 기술 과제**: 고차원 데이터의 피처 엔지니어링, 심각한 클래스 불균형(Class Imbalance) 해소, 그리고 다양한 머신러닝 모델의 앙상블을 통한 예측 안정성 확보.
- **아카이빙 목적**: 대회 순위와 무관하게, 통계적 전처리부터 모델 앙상블에 이르는 정형 데이터(Tabular Data) 처리 역량과 기술 파이프라인 구현 능력을 입증하기 위해 소스 코드를 보존합니다.

## 아카이브 구조 (디렉터리)
루트 경로의 혼잡도를 낮추기 위해 분석 및 훈련을 위해 작성된 모든 주피터 노트북 파일은 `notebooks/` 디렉터리에 보존되어 있습니다. 
실행 시점의 맥락 소실을 방지하고자 원본 파일명을 유지하였으며, 각 파일의 역할은 아래의 매핑 테이블을 참조하십시오.

## 기술 파이프라인 요약
1. **스케일링 및 피처 선택**: `LabelEncoder`와 3종의 스케일러(Standard, MinMax, Robust)를 통해 데이터를 규격화하고, `GenericUnivariateSelect`를 도입해 노이즈 피처를 통계적으로 걸러냈습니다.
2. **데이터 불균형 해소**: 정상 데이터에 편중된 극단적인 비대칭성을 해결하고자 `imblearn`의 `ADASYN` 오버샘플링 기법을 적용하여 소수 클래스의 특성을 증강했습니다.
3. **다중 모델 앙상블**: XGBoost, LightGBM, CatBoost를 비롯한 부스팅 모델과 SVM, KNN 등 비선형 모델 총 8종을 개별 검증하고 랜덤 서치로 튜닝한 뒤, 최종적으로 `VotingClassifier`로 묶어 예측 분산을 최소화했습니다.
