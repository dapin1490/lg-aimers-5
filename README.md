# 2024 LG Aimers 5기 - 제품 불량 여부 예측 모델링

본 저장소는 2024년 7월부터 8월까지 진행된 LG Aimers 5기 해커톤에서, 제품 생산 공장 데이터를 기반으로 제품 불량 여부를 예측하는 이진 분류(Binary Classification) 모델을 실험한 과정을 기록한 아카이브입니다.

## 프로젝트 개요
- **목적**: 제조 공정 데이터를 분석하여, 최종 제품의 정상/불량 상태를 예측하는 모델 개발.
- **문제 특성**: 전체 데이터에서 불량 제품의 비율이 1% 미만인 극심한 클래스 불균형(Class Imbalance) 문제. 모든 제품을 정상으로 예측해도 정확도가 99%에 이르기 때문에 평가 지표로 F1 score를 사용함.
- **참여 형태**: 3인 팀(팀장). 데이터 전처리와 모델 실험 담당.
- **결과**: 본 저장소의 코드로 만든 모델의 테스트 제출 점수는 F1 약 0.21(2024.08.26)입니다. 최종 채점용으로는 다른 팀원이 작성한 코드가 제출되었으며, 해당 코드는 본 저장소에 포함되어 있지 않습니다.
- **아카이빙 목적**: 높은 점수를 얻은 결과물이 아니라, 당시의 실험 과정과 이후의 사후 분석을 함께 남기기 위해 보존합니다.

## 실험 내용 요약
1. **전처리**: 값이 한 종류뿐이거나 전부 비어 있는 컬럼을 삭제하고, 순서가 있는 범주형 값(설비 번호 등)은 번호로 인코딩했습니다. 숫자 컬럼에 'OK' 등 문자열이 섞인 경우를 따로 처리했고, 타깃과의 상관계수가 매우 낮은 컬럼을 제거했습니다.
2. **불균형 대응**: `imblearn`의 `ADASYN`으로 불량 데이터를 오버샘플링한 뒤, 정상 데이터를 언더샘플링해 학습 데이터의 클래스 비율을 조정했습니다.
3. **모델 실험**: KNN, SVM, 결정 트리, 랜덤 포레스트, XGBoost, LightGBM, CatBoost를 비교하고, 이웃 수를 달리한 KNN 여러 개를 `VotingClassifier`(soft)로 결합한 모델로 테스트 제출을 했습니다.
4. **추가 실험(제출 미반영)**: 컬럼 분포에 따른 스케일러 선택, `GenericUnivariateSelect` 기반 피처 선택, Random Search 튜닝, 유전 알고리즘 기반 피처 조합 탐색을 별도 노트북에서 실험했습니다.

## 사후 분석 (2026)
내부 검증에서는 트리·부스팅 계열 모델이 F1 1.0, KNN과 보팅 모델이 F1 약 0.73~0.76을 기록했지만, 테스트 데이터에서는 트리·부스팅 계열이 불량을 거의 0%로 예측했고 제출 점수도 F1 약 0.21에 그쳤습니다. 대회 당시에는 이 격차의 원인을 찾지 못했고, 2년 뒤 코드를 다시 검토하며 다음과 같이 정리했습니다.

1. **검증 데이터가 실제 분포를 대표하지 못했습니다.** 오버샘플링과 언더샘플링을 먼저 적용한 뒤 학습/검증 데이터를 나누었기 때문에, 검증 데이터에 합성된 불량 샘플이 섞이고 불량 비율도 실제보다 훨씬 높아져 검증 점수가 과대평가되었습니다. 샘플링은 데이터를 나눈 뒤 학습 데이터에만 적용했어야 합니다.
2. **도메인을 고려하지 않은 일괄 전처리였습니다.** 각 컬럼의 공정상 의미를 깊이 파악하지 않고, 결측값을 평균이나 -1로 일괄 대체하고 상관계수만으로 컬럼을 제거했습니다.
3. **실험과 제출을 구분해 관리하지 않았습니다.** 여러 노트북에서 실험한 기법 중 무엇이 어느 제출에 반영되었는지 정리하지 않아, 기법별 효과를 분리해서 판단하기 어려웠습니다.
